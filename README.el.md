# PulseGuard

Cloud-native πλατφόρμα απομακρυσμένης παρακολούθησης ασθενών με υπέρταση.
Οι ασθενείς καταγράφουν μετρήσεις αρτηριακής πίεσης από το σπίτι· το σύστημα
τις αξιολογεί με κλινικούς κανόνες και ειδοποιεί τον θεράποντα ιατρό.

> Εκπαιδευτικό project. Όλα τα δεδομένα είναι συνθετικά. Δεν είναι ιατρική συσκευή.

## Τεχνολογίες

Java 25 · Spring Boot 4.1 · PostgreSQL + TimescaleDB · Docker

## Τοπική εκτέλεση

Απαιτήσεις: JDK 25, Docker Desktop

    docker compose up -d
    cd core-service
    ./mvnw spring-boot:run

Έλεγχος υγείας: http://localhost:8080/actuator/health
